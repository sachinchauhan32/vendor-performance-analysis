\# Vendor Performance Analysis



\## 📌 Project Overview



An end-to-end data analytics project focused on analyzing vendor performance, sales behavior, purchasing activity, inventory data, and business KPIs.



The project combines \*\*SQL, Python, and Power BI\*\* to transform raw transactional data into meaningful business insights and an interactive analytical dashboard.



\## 🎯 Business Objective



The primary objective is to understand vendor and sales performance and identify patterns that can support better business decisions around vendors, products, sales, purchasing, and inventory.



\## 🛠️ Tools \& Technologies



\* \*\*SQL\*\* — Data analysis, aggregations, business questions, vendor and inventory analysis

\* \*\*Python\*\* — Data inspection, cleaning, transformation, aggregation, and analytical dataset creation

\* \*\*Pandas\*\* — Data manipulation and analysis

\* \*\*Power BI\*\* — Interactive dashboards, KPIs, visual analysis, and business reporting

\* \*\*Git \& GitHub\*\* — Version control and project portfolio management

\* Top products
